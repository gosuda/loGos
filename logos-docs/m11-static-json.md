# M11 static JSON

Normative sources: `logos-docs/SPEC.md` Sec 12,
`logos-docs/IMPLEMENTATION.md` M11-S1 to S4. This page closes the M11 P1-S3
docs row. It describes the behavior the tree implements; parent runs the
gates below to confirm the checkout.

## What the mechanism is

Generated serializers for eligible `.lgo` struct types (structs with json
tags, defaults, or nonnil pointer fields and no embedded fields; unsupported
field kinds such as interfaces, maps with nonstring keys, or embedded structs
skip generation for that type):

- `MarshalJSON` on the value: fixed key literals with a precomputed size
  bound, then helpers in `src/logos/rt/json` (string escaping, float
  formatting, append helpers matching `encoding/json` defaults: HTML and JS
  escaping, null maps and slices as null, legacy omit empty semantics;
  floats use the shared wire helper). The generated bytes are already compact
  (no second HTML pass). Output equals `json.Marshal` of a methodless mirror
  copy (`type mirror T`).
- `UnmarshalJSON` on the pointer: defaults prefilled, a `_logos_seen` mask
  sized `[(K+63)/64]uint64` plus a required mask constant, key dispatch by
  switch (up to 8 keys) or T-Sec9 perfect hash table (larger), `null` for a
  nonnil field returns `MissingFieldError`, unknown keys are skipped, arrays
  grow incrementally with no preallocation cap.
- Binary encoding (`MarshalBinary`, `UnmarshalBinary`, `AppendBinary`):
  version `0x01`, then fields in declaration order (all integer kinds as 8
  bytes little endian of the 64 bit value, float32 as 4 bytes little endian of
  `Float32bits`, float64 as 8 bytes, bool as `0x00` or `0x01`, string and
  byte slices as uvarint length plus raw bytes, slices and arrays as uvarint
  count plus elements, maps with string keys as uvarint count plus sorted
  entries, nested structs inline, optional as `0x00` absent or `0x01` plus
  payload). Tag options change nothing in binary.
- Closed union values marshal through the dynamic member helper and unmarshal
  by trying members in declaration order into scratch values with single
  success plus ambiguity rules (zero successes return a union error, two or
  more return an ambiguity error naming both members). Comptime generics
  expand once per instantiation with per instantiation static helpers
  (`<f>·logosct1`, `<f>·logosct2`). Call sites are not rewritten.

## How to enable or observe it

- Automatic for eligible structs; no flag. `portability::serialized_unsized_int`
  warns on `int` and `uint` fields (prefer sized kinds).
- Observe with `test/logos/run/json_marshal_test.lgo` (randomized values,
  seed corpus with HTML, U+2028 and U+2029, invalid UTF-8, float exponents,
  byte equality with the mirror type, one allocation for scalar structs),
  the fixed `User` literal shape (6 plus 9 plus 1 plus 1 byte segments, 17
  fixed bytes), `json_binary_test.lgo` (exact layout bytes, truncation and
  bad presence and version and trailing byte errors naming field and offset),
  `json_union_test.lgo`, `json_generic_test.lgo`, and `json_callsite_test.lgo`.
- Parent to run: the testdir JSON run set, the 60 s fuzz leg in the slice
  plus the seed corpus in CI, and the `TestSeenMask` and allocation checks.

## Budgets and defaults

- String escaping and float formatting copy the default experiment set
  (`EscapeForHTML`, `EscapeForJS`, `FormatNilMapAsNull`,
  `FormatNilSliceAsNull`, `OmitEmptyWithLegacySemantics`).
- The binary count header is charged against no total budget, so a count
  whose element bytes are present decodes even when the total exceeds
  1 MiB. Count headers whose elements have nonzero wire payload preallocate
  at most `min(len(rest)/2, 1 MB / sizeof(elem))`, then append as bytes
  arrive. For zero wire elements only the count itself is capped, at
  1,048,576; a larger count fails with a count-out-of-range error in encoder
  and decoder alike, in constant time with respect to count and without per
  element iteration. Each count is capped independently, so fields and
  nested slices are never rejected for their sum.
- Defaults apply before decoding; explicit `false` overrides a default
  `true`. Missing required nonnil field reports
  `logos/rt.MissingFieldError{Type, Field}`.

## Known limits

- Unmodeled fields fall back per field; overlapping shapes can return the
  documented ambiguity error and leave the target untouched.
- The PLAN preallocation cap applies to no code path and is recorded as not
  applicable in the tailored spec.
- A slice count header of 2 to the 40 followed by 10 bytes of input fails with
  truncation before allocation or iteration; growth during the call stays
  below 1 MB in that attack.
- Binary tag options: JSON tags affect JSON only.
